# CA Machine Learning Project

This repository contains the project notebooks, analysis outputs, and figures for the Machine Learning application assignment.

## Dataset

The project uses the [Airlines Review Dataset on Kaggle](https://www.kaggle.com/datasets/elijahconnectng/airlines-review-dataset). The reviewer `Name` field has been removed from the CSV files in this public copy. Saved notebook outputs that displayed that field have also been cleared.
